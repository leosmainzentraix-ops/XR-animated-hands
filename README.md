# XR Animated Hands (.unitypackage)

Rigged and animated hand models designed for XR experiences using the XR Interaction Toolkit.

## Prerequisites
Before importing this package, make sure you have the **XR Interaction Toolkit** installed in your Unity project via the Package Manager.

## Installation

1. Download the `XR_Animated_Hands.unitypackage` file from the [Releases](https://github.com) section of this repository (or from the root folder).
2. Open your Unity project.
3. In Unity, go to **Assets** > **Import Package** > **Custom Package...**
4. Select the downloaded `.unitypackage` file and click **Import**.

## How to Use
1. Once imported, open your Unity Project window and look under your `Assets` folder.
2. Go to: `Assets` > `AnimatedHnds`.
3. Inside the `AnimatedHnds` folder, you will find your hand rig and assets.
4. Drag your hand rigs directly onto your **XR Controller** objects.
